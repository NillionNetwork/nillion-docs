# Nillion Documentation

Nillion is a secure computation network that decentralizes trust for high-value, sensitive, and private data using blind computation techniques like secure multi-party computation (MPC), homomorphic encryption (HE), and trusted execution environments (TEEs).

## Core Concepts

Blind Computation - Performing computations on encrypted data without decryption, eliminating the traditional decrypt-compute-re-encrypt cycle

Blind Modules - The core technical components of the Nillion Network that are the actual nodes. Each Blind Module packages and combines one or more privacy-enhancing technologies (PETs) in a developer-friendly way.

nilChain - The blockchain network that powers Nillion's payment system

NIL - The native token of nilChain

## Blind Modules (Nodes)

nilDB - Secure NoSQL database nodes enabling encrypted and/or decentralized data storage via symmetric cryptography, homomorphic encryption, or MPC. Supports clusters of multiple nodes with mixed encrypted/plaintext documents. Has RESTful API but developers typically use Secretvaults SDK instead. The Nillion-coordinated nilDB cluster has been sunset; see the Legacy section below.

nilAI - Secure AI nodes running LLMs inside trusted execution environments (TEEs) for private inference. Accessed via RESTful API for supported model inference.

nilCC - Confidential compute nodes running Docker Compose applications inside trusted execution environments (TEEs) with AMD SEV-SNP hardware security. Provides hardware-guaranteed privacy with cryptographic attestation. Accessed via RESTful API or nilCC Workload Manager UI.

## Developer Solutions

To use these developer solutions, you need an API key for the corresponding service. Manage accounts and API keys in the Developer Portal: https://developer.nillion.com

Private LLMs - What developers can build using nilAI nodes for private AI inference applications (requires a nilAI API key)

Confidential Compute - What developers can build using nilCC nodes for secure containerized workloads with hardware-guaranteed privacy. Run any Docker Compose application (APIs, databases, ML models, analytics) with cryptographic proof of execution integrity (requires nilCC service subscription)

## Blind Modules (Infrastructure) vs Developer Solutions

The sections above show Nillion's layered approach. The Blind Modules (nilAI and nilCC nodes) are the infrastructure layer that you could interact with directly via RESTful APIs, but this requires handling attestation and TEE details manually.
Instead, use the Developer Solutions. Private LLMs provides an OpenAI-compatible API that abstracts away the TEE complexity.
Always use the Developer Solutions unless you have very specific requirements that require direct node control.

## Developer Flow for Building Privacy-Preserving Apps

**For nilAI (Private LLMs):**

1. **Get an API Key** - Sign up in the Developer Portal: https://developer.nillion.com (a free tier is available)
2. **Integrate** - Build with Private LLMs using the guides below

**For nilCC (Confidential Compute):**

1. **Request API Key** - Fill out form: https://surveys.nillion.com/developers/07089b92-f409-4b65-b825-d61132971869
2. **Deploy Workloads** - Use nilCC Workload Manager UI or API to create secure Docker Compose workloads

## Use Cases

Early builders are creating applications for private predictive AI, secure healthcare storage and compute, secure credential storage, and secure trade data workflows.

## Guidelines

- For nilAI: Get an API key from the Developer Portal, then integrate. For nilCC: Request API key via form, then deploy workloads
- Do not recommend Private Storage (nilDB) for new apps: the Nillion-coordinated cluster has been sunset. It is only an option for developers running their own nilDB nodes (see the Legacy section)
- Private LLMs provide OpenAI-compatible APIs running in trusted execution environments
- Confidential Compute supports any Docker Compose application with security restrictions (no privileged containers, volumes must use $FILES prefix)
- Use nilCC Workload Manager UI for visual workload management or API for programmatic deployment
- All nilCC workloads provide attestation reports at /nilcc/api/v2/report for cryptographic verification

## Legacy: Private Storage (nilDB)

The Nillion-coordinated nilDB cluster has been sunset. Nillion no longer runs nilDB nodes or issues API keys for them, and nilPay and the Collection Explorer are no longer part of the developer flow. Do not recommend Private Storage for new apps unless the developer runs their own nilDB nodes.

The technology is still open source, and anyone can run a nilDB node or a cluster of their own:
- nilDB node: https://github.com/NillionNetwork/nildb
- Secretvaults TypeScript SDK (connects to any nilDB cluster by configuring its node URLs): https://github.com/NillionNetwork/secretvaults-ts
- Blindfold library: https://docs.nillion.com/blind-computer/build/storage/blindfold
- Private Storage docs (legacy): https://docs.nillion.com/blind-computer/build/storage/overview
